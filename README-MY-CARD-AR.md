# ميزة «بطاقتي / My Card» — AKGYM

تتيح الواجهة للعضو إدخال رقم العضوية ورقم الهاتف المسجل في النادي، ثم تعرض بطاقته الرقمية ورمز QR وملخص الاشتراك وتاريخ الانتهاء وعدد مرات الحضور المسجلة. بيانات الاشتراك في نظام الإدارة الحالي مبنية على مدة زمنية، لذلك لا يعرض النظام إجمالي جلسات أو جلسات متبقية غير موجودة فعلياً في قاعدة البيانات.

## إعداد الربط مرة واحدة

1. في مشروع Vercel الخاص بالموقع، اضبط `KV_REST_API_URL` و`KV_REST_API_TOKEN` (أو أسماء Upstash المكافئة) لقاعدة Redis التي تستخدمها واجهة العروض.
2. أضف `AKGYM_PUBLISH_TOKEN` في Vercel بقيمة عشوائية طويلة (32 حرفاً أو أكثر). استخدم القيمة نفسها في ملف `.env` الخاص بالإدارة، ولا تضعها في ملفات الواجهة أو Git.
3. في ملف `.env` للإدارة، اضبط:
   - `AKGYM_PUBLISH_TOKEN` بالقيمة نفسها الموجودة في Vercel.
   - `PUBLIC_OFFERS_API_URL=https://YOUR-DOMAIN/api/offers`
   - `PUBLIC_MEMBER_SYNC_API_URL=https://YOUR-DOMAIN/api/members-sync`
4. أعد تشغيل نظام الإدارة. من لوحة المدير افتح «عروض الموقع الرسمي»:
   - اضغط «حفظ محلياً» ثم «نشر على الموقع» لنشر العروض.
   - اضغط «مزامنة بطاقات المشتركين» لنشر بيانات البطاقة الضرورية فقط.
5. أعد المزامنة بعد تغيير أرقام الهواتف أو بيانات الاشتراك أو إضافة/تعطيل عضو. يمكن طباعة الباركود الخطي Code 128 من جدول الأعضاء في لوحة الإدارة؛ بطاقة الموقع تعرض رمز QR للعضو نفسه.

## حماية بيانات الأعضاء

- واجهة مزامنة الأعضاء `POST /api/members-sync` تقبل طلبات الإدارة الموقعة بالتوكن فقط، ولا توفر مساراً عاماً لعرض قائمة الأعضاء.
- تُنشر فقط بيانات البطاقة اللازمة: رقم العضوية، رقم الهاتف للتحقق، الاسم، قيمة الرمز، ملخص الاشتراك، وعدّاد الحضور. لا تُنشر الملاحظات أو الدفعات أو السجلات الداخلية.
- واجهة البطاقة لا تعيد البيانات إلا بعد مطابقة رقم العضوية والهاتف، وتطبق حدوداً لمحاولات التخمين، وتمنع التخزين المؤقت للردود.
- هذه الحماية لا تجعل رقم الهاتف بمثابة كلمة مرور قوية. لا تعرض عبر البطاقة بيانات مالية أو حساسة. إذا أردت مستوى حماية أعلى، أضف رمز تحقق لمرة واحدة.
- قاعدة SQLite المحلية وملف `.env` لا يجب رفعهما إلى Git أو Vercel.

## اختبار إلزامي قبل الاستخدام الحقيقي

1. انشر بيانات عضو لديه رقم هاتف صالح، ثم تحقق من أن رقم العضوية والهاتف الصحيحين يعرضان بطاقته.
2. جرّب هاتفاً خاطئاً ورقم عضوية غير موجود؛ يجب أن تظهر رسالة تحقق عامة.
3. جرّب عضواً آخر وتأكد أنه لا يستطيع مشاهدة بطاقة العضو الأول.
4. غيّر الاشتراك أو الهاتف، ثم أعد المزامنة وتأكد من ظهور البيانات الجديدة.
5. اختبر QR والباركود الخطي بقارئ النادي الفعلي؛ بعض أجهزة القراءة تقبل Code 128 ولا تقرأ QR.
6. تأكد من أن بيانات العروض لا تحتوي على معلومات شخصية.
