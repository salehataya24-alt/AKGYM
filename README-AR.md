# AKGYM Website — نسخة مجهزة مع عروض قابلة للتحديث

## التشغيل المحلي
- فك ضغط المجلد.
- افتح Terminal داخل المجلد.
- شغّل `python -m http.server 8080` أو `npx serve .`
- افتح `http://localhost:8080`.

> لا تفتح `index.html` مباشرة عبر `file://` إذا كنت تريد اختبار تحميل `offers.json`، لأن المتصفح قد يمنع fetch من الملفات المحلية.

## إدارة عروض الموقع
الواجهة تقرأ العروض من الملف `offers.json` في نفس المجلد. عند نشر الموقع، ارفع الملف بجانب `index.html` و`script.js`.
كل عنصر داخل `offers` يقبل الحقول:
- `id`: معرف فريد.
- `active`: `true` للنشر أو `false` للإخفاء.
- `tag`, `arTag`: الشارة بالإنجليزية والعربية.
- `num`, `unit`: قيمة العرض وعلامتها (مثلاً `20` و`%`).
- `title`, `arTitle`, `desc`, `arDesc`, `btn`, `arBtn`.
- `type`: `uni` لفتح نافذة عرض الطلاب، أو `wa` لفتح واتساب.
- `msg`: نص واتساب عند استخدام `type: "wa"`.
- `startDate`, `endDate`: اختياري، بصيغة `YYYY-MM-DD`.

تُقرأ العروض من جديد عند تحميل الصفحة، وتُخفى العروض المعطلة أو خارج فترة الصلاحية. في حال تعذّر تحميل `offers.json`، يستخدم الموقع العرض الافتراضي المضمّن.

## مهم: الربط مع نظام إدارة النادي
هذه النسخة تجعل قسم العروض ديناميكياً عبر `offers.json`، لكنها **ليست بعدُ مزامنة تلقائية مع نظام إدارة النادي المحلي**. لأن نظام النادي مصمم ليبقى داخل شبكة النادي فقط، لا يمكن للموقع العام قراءة قاعدة بياناته مباشرة بأمان. للنشر التلقائي يجب إعداد واجهة نشر وسيطة على استضافة HTTPS، مع مصادقة وصلاحية نشر للعروض فقط، ومن دون إتاحة بيانات اللاعبين أو فتح نظام النادي للإنترنت. يلزم تحديد مزود الاستضافة/عنوان الموقع قبل تهيئة هذا الاتصال النهائي.

## اختبار الملفات
- افحص صياغة JavaScript بواسطة `node --check script.js`.
- اختبر الموقع عبر خادم HTTP محلي، وليس `file://`.
- اختبر تبديل العربية والإنجليزية، ثم عطّل عرضاً أو حدّد تاريخ انتهاء في `offers.json` وتأكد من اختفائه.


## النشر التلقائي للعروض عبر Vercel (إعداد مطلوب مرة واحدة)
1. ارفع مجلد الموقع إلى مستودع Git واربطه بمشروع Vercel، واجعل مجلد الموقع هو Root Directory.
2. أنشئ قاعدة Redis متوافقة مع Upstash من تكامل Vercel، وأضف متغيري البيئة `KV_REST_API_URL` و`KV_REST_API_TOKEN` (أو `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN` حسب الأسماء التي يوفرها التكامل) إلى إعدادات مشروع Vercel.
3. أنشئ رمزاً عشوائياً طويلاً وفريداً، وأضفه باسم `AKGYM_PUBLISH_TOKEN` في Vercel. احتفظ به سراً ولا تضعه في ملفات الواجهة أو Git.
4. أعد النشر بعد حفظ متغيرات البيئة. جرّب `GET /api/offers`؛ عند الإعداد الصحيح يجب أن يرجع JSON حتى لو كانت قائمة العروض فارغة.
5. انسخ الرابط `https://YOUR-DOMAIN/api/offers` والرمز إلى ملف `.env` في نظام النادي المحلي باستخدام `WEBSITE_OFFERS_API_URL` و`WEBSITE_OFFERS_PUBLISH_TOKEN`. لا ترفع ملف `.env` إلى Git أو ترسله لأحد.
6. من لوحة المدير اضغط «نشر على الموقع الرسمي». الطلب يرسل بيانات العروض فقط، ولا يرسل أسماء اللاعبين أو الاشتراكات أو قاعدة البيانات.

مهم: لن يعمل النشر حتى تضبط قاعدة Upstash ومتغيرات Vercel وملف `.env` المحلي ثم تعيد تشغيل نظام النادي.


## بطاقة العضو My Card ومزامنة البيانات

- صفحة «بطاقتي» تستخدم QR حقيقياً محلي التوليد، وتتحقق من رقم العضوية/الرقم الوطني ورقم الموبايل المسجل.
- لا تضع قاعدة SQLite أو ملف `.env` على Vercel. جهاز النادي يرسل لقطة مختصرة عبر HTTPS إلى `/api/member-sync`، ويظل السيرفر المحلي غير متاح من الإنترنت.
- راجع `README-MY-CARD-AR.md` لإعداد `MEMBER_SYNC_API_TOKEN` وUpstash واختبار المزامنة.
- إذا تعذر جلب العروض على الموقع المنشور، تظهر رسالة عدم وجود عروض بدلاً من عرض بيانات افتراضية قديمة.
